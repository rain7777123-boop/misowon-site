작성일: 2026-10-25 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
24년차 원장이 몸의 정렬을 바탕으로 리프팅·윤곽, 전신 순환, 몸의 불편함을 1:1로 관리하는 일산 하이파크 에스테틱 샵(100% 예약제).

## 2. 손님
- 누가: 특정 고민이 있는 손님. 리프팅·윤곽 관리, 전신 순환, 몸이 아픈 사람이 주된 대상이다. 일반 에스테틱 샵과 다르다는 점이 보여야 한다.
- 어디서 알고 오나: 지금은 주로 네이버 검색·플레이스. 앞으로 블로그와 인스타 영상을 적극적으로 만들 계획이다.

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 내 고민에 맞는 관리가 무엇인지
2. 가격
3. 효과와 관리 과정 (어떻게 진행되는지)

## 4. 믿게 할 증거 (실제로 있는 것만)
- 경력: 24년차 (사용자가 "더 늘었다"고 함, 정확한 연차는 나중에 다시 알려 주기로 함. 그 전까지 "24년차"로 쓴다)
- 공부 이력: 해부학 이수, 카이로프랙틱·근막 테라피 연구 (네이버 플레이스 소개글 기준)
- 자격증·수료증 사진: 있음 (사진 파일은 사용자가 준다. 받기 전까지 자리만)
- 후기: 실제 손님 후기 있음 (내용은 사용자가 고르거나 준다. 받기 전까지 자리만, 지어내지 않는다)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 네이버 예약하기
- 누르면: 네이버 예약 화면으로 이동 (주소는 미정, 사용자에게 받는다. 참고: 플레이스 주소 https://pcmap.place.naver.com/place/36123687/home)
- 보조: 고민 상담 문의 폼 (아래 7번)

## 6. 페이지 구성 (위에서 아래로, 한 장짜리)
1. 첫 화면 — 한 문장 + [네이버 예약하기] 버튼
2. 이런 고민이라면 — 리프팅·윤곽 / 전신 순환·체형 / 몸이 불편한 분(거북목·라운드숄더·오십견 등), 일반 에스테틱과 다른 점 한 줄
3. 관리 메뉴와 가격 — Body Reset / Face Fit, 회원가·1회가 함께, "VAT 별도" 표시 (8번 그대로)
4. 원장 소개 — 24년차, 공부 이력, 자격증·수료증 사진 자리
5. 관리 과정 — 상담 → 몸 상태 확인 → 1:1 맞춤 관리 (세부 단계는 미정, 사용자 확인 후 채움)
6. 후기 자리 — 실제 후기를 받으면 넣는다
7. 블로그·영상 — 네이버 블로그 연결, 인스타·영상은 자리만 ("준비 중")
8. 오시는 길·영업시간
9. 고민 상담 문의 폼
- 별도 페이지: /admin (문의 확인용 관리자 페이지)

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 따뜻한 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel
- 문구: 플레이스 소개글의 과장 표현("독보적", "압도적")은 쓰지 않는다

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
